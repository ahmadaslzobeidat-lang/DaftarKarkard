پروژه اندرویدی «دفتر کارکرد من»
================================

این فایل یک پروژه منبع اندروید است، نه APK آماده نصب.
برای ساخت APK بدون کامپیوتر، از GitHub Actions استفاده شده است.

مراحل با گوشی:
1) وارد github.com شوید و یک حساب رایگان بسازید یا وارد حساب شوید.
2) یک مخزن (Repository) جدید با نام DaftarKarkard بسازید.
3) فایل ZIP پروژه را از حالت فشرده خارج کنید و همه محتویات پوشه DaftarKarkard-Android را در مخزن بارگذاری کنید.
   در وب‌سایت GitHub می‌توانید Add file > Upload files را بزنید.
4) پس از بارگذاری، زبانه Actions را باز کنید.
5) اجرای workflow با نام Build Android APK را انتخاب کنید و Run workflow را بزنید.
6) پس از پایان موفق، وارد اجرای انجام‌شده شوید و از بخش Artifacts فایل
   daftar-karkard-debug-apk را دانلود کنید.
7) ZIP دانلودشده را باز کنید؛ فایل app-debug.apk داخل آن است. آن را روی گوشی نصب کنید.
   ممکن است اندروید اجازه نصب از منبع مورد استفاده را بخواهد.

مشخصات پروژه:
- اپلیکیشن Android با WebView داخلی و فایل HTML داخل برنامه
- حداقل Android 8 (API 26)، هدف ساخت API 35
- داده‌ها در فضای محلی WebView ذخیره می‌شوند

محدودیت‌های فعلی:
- این پروژه فقط بسته‌بندی اندرویدی نسخه فعلی است.
- ورود/ثبت‌نام ایمیلی و همگام‌سازی/پشتیبان‌گیری ابری هنوز پیاده‌سازی نشده‌اند.
- پشتیبان‌گیری فعلی محلی است؛ فایل JSON را جداگانه در فضای ابری یا جای امن ذخیره کنید.
- خروجی فعلی APK دیباگ است و برای انتشار عمومی باید نسخه release با کلید امضای اختصاصی ساخته شود.
- قابلیت عربی در نسخه فعلی کامل ترجمه نشده است.
